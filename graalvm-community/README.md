
# GraalVM Community Edition Container Images

GraalVM is an advanced JDK with ahead-of-time Native Image compilation.
GraalVM Community Edition container images are published in this GitHub Container Registry.
Read more [on the official website](https://www.graalvm.org/getting-started/container-images/).

## How to Use These Images

Use these images in the `FROM` instruction of a downstream Dockerfile. For example:

```dockerfile
FROM ghcr.io/graalvm/graalvm-community:latest
```

## Building Images

The Dockerfiles use the GraalVM version specified by their `GRAALVM_VERSION` build argument.
From this directory, run the following commands to build local Oracle Linux 9 images for AMD64 and AArch64:

```shell
docker buildx build --platform linux/amd64 -t graalvm-community:java25-ol9-amd64 --output=type=docker -f Dockerfile.ol9-java25 .
```

```shell
docker buildx build --platform linux/arm64 -t graalvm-community:java25-ol9-arm64 --output=type=docker -f Dockerfile.ol9-java25 .
```

To use another Oracle Linux version, replace `Dockerfile.ol9-java25` with `Dockerfile.ol8-java25` or `Dockerfile.ol10-java25`.
